# Low-Level Objective-C Runtime ABI Layer (`src/raw/`)

The `src/raw/` subsystem is the authoritative, explicit, pure-Zig boundary between the Zig language and Apple's `libobjc` runtime library.

---

## 1. Architectural Philosophy

1. **Zero Translation Overhead in Production**:
   Production builds of `zobjc` do not invoke `translate-c` or `@cImport`. All function prototypes, handle types, bitfields, and ABI structs are handwritten directly in Zig, linking directly to `-lobjc`.

2. **Strict Layering**:
   ```text
   High-Level Subsystems (runtime, messaging, memory, block, encoding)
                              ↓
                      src/raw/ (Pure Zig ABI)
                              ↓
                     Apple libobjc / libSystem
   ```
   No module above `src/raw/` may directly import C headers or declare ad-hoc `extern "c"` runtime functions.

3. **1:1 Naming & Signatures**:
   All declarations preserve Apple's exact C names (e.g. `objc_msgSend`, `class_addMethod`, `sel_registerName`).

---

## 2. Type Mappings & ABI Conventions

### 2.1 Fundamental Handles

| Objective-C C Type | Zig `raw` Type | Description |
| :--- | :--- | :--- |
| `id` | `pub const id = ?*objc_object;` | Nullable object handle |
| `Class` | `pub const Class = ?*objc_class;` | Nullable class handle |
| `SEL` | `pub const SEL = ?*objc_selector;` | Nullable selector handle |
| `IMP` | `pub const IMP = ?*const fn () callconv(.c) void;` | Untyped method implementation pointer |
| `Method` | `pub const Method = ?*objc_method;` | Method descriptor pointer |
| `Ivar` | `pub const Ivar = ?*objc_ivar;` | Instance variable pointer |
| `objc_property_t` | `pub const objc_property_t = ?*objc_property;` | Property handle |
| `Protocol *` | `pub const Protocol = ?*objc_object;` | Protocol handle (in C, `typedef struct objc_object Protocol;`) |
| `Category` | `pub const Category = ?*objc_category;` | Category handle |

### 2.2 Target-Aware `BOOL`

Apple defines `BOOL` conditionally depending on the target OS and architecture:
- **macOS / Mac Catalyst / 32-bit legacy**: `typedef signed char BOOL;` (`i8`)
- **64-bit iOS, tvOS, watchOS, visionOS**: `typedef bool BOOL;` (`bool`)

`zobjc` defines `BOOL` target-sensitively in [`src/raw/types.zig`](file:///Users/burakssen/dev/personal/apple/zobjc/src/raw/types.zig):

```zig
pub const BOOL = if (objc_bool_is_bool) bool else i8;
pub const YES: BOOL = if (objc_bool_is_bool) true else 1;
pub const NO: BOOL = if (objc_bool_is_bool) false else 0;
```

Conversion helpers are provided in [`src/raw/root.zig`](file:///Users/burakssen/dev/personal/apple/zobjc/src/raw/root.zig):
- `raw.boolResult(result: BOOL) bool`: converts target `BOOL` to Zig `bool`.
- `raw.boolParam(param: bool) BOOL`: converts Zig `bool` to target `BOOL`.

### 2.3 Strings & Nullability

- Null-terminated C strings: `[*:0]const u8` (when non-null) or `?[*:0]const u8` (when nullable).
- Mutable C strings: `?[*:0]u8` or `?[*]u8`.
- Span conversion: `std.mem.span(ptr)` converts non-null `[*:0]const u8` into `[:0]const u8`.

## 3. Subsystem Modules

The `src/raw/` directory is organized into focused modules:

```text
src/raw/
├── root.zig               # Public facade, types re-exports, bool helpers, backward-compat bridge
├── types.zig              # Handles, ABI structs, target BOOL definition
├── availability.zig       # Target dispatch predicates (has_msgSendStret, etc.)
├── objc.zig               # <objc/objc.h> selector and object functions
├── runtime.zig            # <objc/runtime.h> & <objc/objc-sync.h> (117 declarations)
├── message.zig            # <objc/message.h> dispatch primitives
├── blocks.zig             # BlocksRuntime ABI, flags, literals, copy/release
├── compiler_runtime.zig   # ARC entry points and <objc/objc-exception.h>
└── deprecated.zig         # Obsolete / deprecated declarations
```

### 3.1 Architecture-Guarded Message Dispatch (`message.zig`)

On x86_64, Darwin requires dedicated entry points for structure and floating-point returns:
- `objc_msgSend_stret` / `objc_msgSendSuper_stret`
- `objc_msgSend_fpret` / `objc_msgSendSuper_fpret`
- `objc_msgSend_fp2ret`

On ARM64 (aarch64), Apple's ABI passes structures and floats in general/SIMD registers and uses unified `objc_msgSend`. The stret entry points do not exist in `libobjc` on ARM64.

`src/raw/availability.zig` inspects `builtin.target.cpu.arch`:
- Attempting to reference unavailable entry points on ARM64 produces a clear compile-time error.

## 4. Verification & Parity Testing

1. **Parity Tests (`tests/raw/parity_test.zig`)**:
   Compares size, alignment, and field offsets between Zig handwritten declarations and Apple SDK header translations generated by `translate-c`.

2. **Automated Header Audit (`tools/audit-runtime-api.py`)**:
   Scans Apple SDK headers (`<objc/objc.h>`, `<objc/runtime.h>`, `<objc/message.h>`, `<objc/objc-sync.h>`, `<objc/objc-exception.h>`), extracting all `OBJC_EXPORT` functions and verifying 100% declaration coverage.
