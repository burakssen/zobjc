# Getting Started with zobjc

This guide introduces the core workflows of `zobjc`: importing the library, looking up classes, sending messages, managing object lifetimes, and using blocks.

---

## 1. Installation

Add `zobjc` to your project's `build.zig.zon`:

```zig
.{
    .name = .my_app,
    .version = "0.1.0",
    .dependencies = .{
        .zobjc = .{
            .url = "https://github.com/mitchellh/zig-objc/archive/refs/tags/v1.0.0.tar.gz",
            .hash = "...", // Generated by zig fetch
        },
    },
    .paths = .{ "" },
}
```

In your `build.zig`, import the core `objc` module:

```zig
const zobjc = b.dependency("zobjc", .{
    .target = target,
    .optimize = optimize,
});

exe.root_module.addImport("objc", zobjc.module("objc"));
```

> [!NOTE]
> `zobjc` core links only to Apple's `libobjc.A.dylib` and `libSystem.B.dylib`. It does **not** link `Foundation.framework` by default.

---

## 2. Core Concepts

In `zobjc`, runtime handles are lightweight, non-owning pointers:
- `objc.Object`: A non-owning handle to an instance (`id`).
- `objc.Class`: A non-owning handle to a class (`Class`).
- `objc.Selector`: A non-owning handle to a method selector (`SEL`).

Because handles are non-owning, they never retain or release memory automatically.

## 3. Quick Walkthrough

### Step 1: Looking Up Classes and Selectors
```zig
const std = @import("std");
const objc = @import("objc");

pub fn main() !void {
    // Look up an existing Objective-C class (panics if not linked)
    const NSObject = objc.requireClass("NSObject");

    // Print class name
    std.debug.print("Class: {s}\n", .{NSObject.name()});

    // Register a selector
    const init_sel = objc.sel("init");
    _ = init_sel;
}
```

### Step 2: Sending Messages with `objc.send`
Messages are sent using `objc.send(ReturnType, receiver, selector, args_tuple)`:

```zig
// Allocate a new NSObject instance
const raw_instance = objc.send(objc.Object, NSObject, "alloc", .{});

// Initialize the instance
const instance = objc.send(objc.Object, raw_instance, "init", .{});
```

Alternatively, handles provide convenience `.send(...)` methods:

```zig
const instance = NSObject.send(objc.Object, "alloc", .{})
                         .send(objc.Object, "init", .{});
```

### Step 3: Managing Lifetimes with `Retained`
Objective-C objects allocated with `+alloc`, `+new`, or `-copy` carry a `+1` retain count. Wrap them in `objc.Retained(T)` to ensure deterministic deallocation with Zig's `defer`:

```zig
// Adopt the +1 ownership obligation
var owned = objc.Retained(objc.Object).adopt(
    NSObject.send(objc.Object, "new", .{})
);
defer owned.deinit(); // Automatically calls objc_release when leaving scope

// Borrow non-owning handle to call methods
const cls = owned.borrow().class();
std.debug.print("Instance class: {s}\n", .{cls.name()});
```

### Step 4: Autorelease Pools
When calling APIs that return autoreleased objects, manage the pool lifetime with `objc.AutoreleasePool`:

```zig
{
    var pool = objc.AutoreleasePool.init();
    defer pool.deinit(); // Drains all autoreleased objects in this scope

    // Autoreleased operations run safely here...
}
```

### Step 5: Creating and Invoking Blocks
Objective-C Blocks are created using `objc.OwnedBlock`:

```zig
// Non-capturing block from a function
var doubler = try objc.OwnedBlock(fn (c_int) c_int).fromFunction(struct {
    fn run(x: c_int) c_int {
        return x * 2;
    }
}.run);
defer doubler.deinit();

// Call directly from Zig
const answer = doubler.call(.{ @as(c_int, 21) });
try std.testing.expectEqual(@as(c_int, 42), answer);
```

## 4. Optional Foundation Framework

If your application interacts with Foundation classes (`NSString`, `NSArray`, `NSDictionary`), import the optional `objc_foundation` module in `build.zig`:

```zig
exe.root_module.addImport("objc_foundation", zobjc.module("objc_foundation"));
exe.linkFramework("Foundation");
```

In your Zig source:

```zig
const objc = @import("objc");
const foundation = @import("objc_foundation");

pub fn printGreeting() !void {
    var pool = objc.AutoreleasePool.init();
    defer pool.deinit();

    // Convert Zig UTF-8 slice to an NSString
    var str = try foundation.string.toNSString("Hello from zobjc 1.0!");
    defer str.deinit();

    const len = objc.send(usize, str.borrow(), "length", .{});
    std.debug.print("NSString length: {d}\n", .{len});
}
```
