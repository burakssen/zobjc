# Objective-C Type Encoding and Signature System

This document defines the architecture, type grammar, AST representations, and compile-time/runtime encoding facilities in `zobjc`.

---

## 1. Architectural Scope and Boundaries

The encoding subsystem (`src/encoding/`) provides a **pure-Zig, bidirectional bridge** between Zig types, Apple Objective-C runtime type encoding strings, and structured ASTs.

```text
               ┌────────────────────────┐
               │        Zig Type        │
               └───────────┬────────────┘
                           │ comptimeEncode(T)
                           ▼
┌────────────────────────────────────────────────────────┐
│             Objective-C Type Encoding String           │
│      (e.g., "i", "@", "{CGPoint=dd}", "v24@0:8i16")    │
└────────────┬──────────────────────────────▲────────────┘
             │ parse(allocator, str)        │ encode(allocator, ast)
             ▼                              │
┌───────────────────────────────────────────┴────────────┐
│                    Semantic Type AST                   │
│        (QualifiedType, Scalar, Aggregate, ...)         │
└────────────────────────────────────────────────────────┘
```

### Strict Separation of Concerns
- **Encoding & Parsing (Phase 4)**: Responsible solely for lexical parsing, semantic AST representations, compile-time type verification, and string generation.
- **ABI Classification & Register Sizing (Deferred to Phase 5)**: The encoding AST deliberately does *not* perform Darwin AAPCS64/x86_64 ABI register classification or pass-by-reference splitting. That is the exclusive responsibility of the Phase 5 dispatch engine.
- **Dynamic Class Registration (Deferred to Phase 7)**: Method type strings generated by `methodEncoding(Fn)` will be consumed by `ClassBuilder` in Phase 7.

## 2. Type Grammar and AST Representation

Objective-C runtime encodings encode scalar primitives, objects, classes, selectors, pointers, C strings, arrays, structures, unions, bitfields, blocks, atomics, and qualifier prefixes.

### 2.1 The Semantic AST Hierarchy (`src/encoding/type.zig`)

```zig
pub const QualifiedType = struct {
    type: Type,
    qualifiers: Qualifiers = .{},
    ...
};

pub const Type = union(enum) {
    scalar: Scalar,
    object: ObjectType,
    class: void,
    selector: void,
    c_string: void,
    pointer: PointerType,
    array: ArrayType,
    structure: AggregateType,
    union_type: AggregateType,
    bitfield: BitFieldType,
    block: BlockType,
    atomic: AtomicType,
    unknown: void,
};
```

### 2.2 Qualifiers (`Qualifiers`)
Qualifiers decorate type encodings in method signatures and ivars:
| Prefix | AST Field | Meaning |
|:---|:---|:---|
| `r` | `is_const` | `const` qualifier |
| `n` | `is_in` | `in` parameter |
| `N` | `is_inout` | `inout` parameter |
| `o` | `is_out` | `out` parameter |
| `O` | `is_bycopy` | `bycopy` return / parameter |
| `R` | `is_byref` | `byref` return / parameter |
| `V` | `is_oneway` | `oneway` void return |

### 2.3 Aggregates and Objects
- **`ObjectType`**: Handles raw `@`, detailed class names (`@"NSString"`), protocol lists (`@"<NSCopying><NSMutableCopying>"`), or combined class and protocol lists (`@"NSArray<NSCopying>"`).
- **`AggregateType`**: Handles named or anonymous structures (`{name=...}` or `{?=...}`) and unions (`(name=...)` or `(?=...)`). Fields may be fully typed or opaque (omitted types in truncated metadata). Quoted field names (`"fieldName"type`) emitted by modern Clang are fully parsed into `Field.name`.
- **`BlockType`**: Represents `@?` (untyped block pointer) or `@?<signature>` (block pointer with signature).
- **`AtomicType`**: Represents `A<type>` (C11/C++11 atomic types).

## 3. Compile-Time Type Encoding (`comptimeEncode`)

`objc.encoding.comptimeEncode(comptime T: type)` converts any valid Zig type into an Objective-C encoding string at compile time with zero runtime allocation overhead.

### 3.1 Type Mapping Table

| Zig Type | Objective-C Encoding | Notes |
|:---|:---|:---|
| `void` | `v` | Method return only |
| `bool` | `B` (Darwin aarch64) / `c` (Darwin x86_64) | Matches Apple `__OBJC_BOOL_IS_BOOL` |
| `c_char`, `i8` | `c` | Signed 8-bit char |
| `u8` | `C` | Unsigned 8-bit char |
| `c_short`, `i16` | `s` | Signed 16-bit short |
| `c_ushort`, `u16` | `S` | Unsigned 16-bit short |
| `c_int`, `i32` | `i` | Signed 32-bit int |
| `c_uint`, `u32` | `I` | Unsigned 32-bit int |
| `c_long` | `q` (LP64) / `l` (ILP32) | Clang 64-bit Darwin encodes as `q` |
| `c_ulong` | `Q` (LP64) / `L` (ILP32) | Clang 64-bit Darwin encodes as `Q` |
| `c_longlong`, `i64`| `q` | Signed 64-bit integer |
| `c_ulonglong`, `u64`| `Q` | Unsigned 64-bit integer |
| `i128` | `t` | Signed 128-bit int |
| `u128` | `T` | Unsigned 128-bit int |
| `f32` | `f` | 32-bit float |
| `f64` | `d` | 64-bit double |
| `f128`, `c_longdouble` | `D` | Long double |
| `*anyopaque`, `?*anyopaque` | `^v` | Generic pointer |
| `[*c]const u8`, `[*:0]const u8` | `r*` | Const C string |
| `[*c]u8`, `[*:0]u8` | `*` | Mutable C string |
| `objc.Object`, `raw.id` | `@` | Generic object reference |
| `objc.Class`, `raw.Class` | `#` | Class reference |
| `objc.Selector`, `raw.SEL` | `:` | Selector handle |
| `[N]T` | `[N<enc(T)>]` | Array of N elements |
| `extern struct` | `{Name=<enc(field)>...}` | C-compatible struct |
| `extern union` | `(Name=<enc(field)>...)` | C-compatible union |

### 3.2 Explicit Custom Overrides
Types may explicitly declare their Objective-C type encoding or structure name:
```zig
const CustomUUID = extern struct {
    pub const objc_type_encoding = "[16C]";
    bytes: [16]u8,
};

const CGPoint = extern struct {
    pub const objc_encoding_name = "CGPoint";
    x: f64,
    y: f64,
};
```

### 3.3 Compile-Time Rejections
To guarantee ABI safety, `assertObjCEncodable(T)` triggers compile-time errors for types without guaranteed C representation:
- Non-extern Zig structs (undefined layout)
- Packed structs (cannot be expressed as C struct ABI)
- Zig tagged unions (contain hidden tag fields)
- Slices `[]T` (two-word fat pointers)
- Error unions `!T` (Zig-specific error codes)

## 4. Method Signatures and Callbacks

### 4.1 Parsing Method Type Encodings (`parseMethod`)
Objective-C method type strings encode the return type, total stack frame size, and all parameter types with their stack offsets:
```text
v24@0:8i16
││  ││ ││ └─ Arg 2: int at stack offset 16
││  ││ └─── Arg 1: SEL (: ) at stack offset 8
││  └────── Arg 0: self (@) at stack offset 0
│└───────── Total stack frame size: 24 bytes
└────────── Return type: void (v)
```

`parseMethod(allocator, str)` parses compact strings (`v@:i`) and annotated strings with stack offsets (`v24@0:8i16`), returning a `MethodSignature` AST.

### 4.2 Generating Method Encodings from Zig Function Types (`methodEncoding`)
Given a Zig C-ABI callback function type, `objc.encoding.methodEncoding(F)` computes the compact Objective-C method type string at compile time:
```zig
const Callback = fn (objc.Object, objc.Selector, c_int) callconv(.c) void;
const enc = objc.encoding.methodEncoding(Callback); // "v@:i"
```

Validation guarantees:
1. `F` must be a function type with calling convention `.c`.
2. `F` must have at least two parameters (`self` and `_cmd`).
3. Parameter 0 must be an object reference (`Object`, `raw.id`, `Class`, or `raw.Class`).
4. Parameter 1 must be a selector (`Selector` or `raw.SEL`).
5. All return and parameter types must satisfy `assertObjCEncodable`.

## 5. Declared Property Attributes (`parseProperty`)

`objc.encoding.parseProperty(allocator, attributes)` parses the comma-separated attribute string returned by `property_getAttributes`:
```text
T@"NSString",R,C,N,V_title
├── T@"NSString" -> QualifiedType (object, class_name = "NSString")
├── R            -> readonly = true
├── C            -> copy = true
├── N            -> nonatomic = true
└── V_title      -> ivar = "_title"
```

## 6. Runtime Entity Introspection Integration

The Phase 2 runtime handles expose direct, ergonomic access to the Phase 4 parser:

```zig
// Method introspection
var sig = try method.parsedSignature(allocator);
defer sig.deinit(allocator);

// Ivar introspection
if (try ivar.parsedType(allocator)) |*ivar_type| {
    defer ivar_type.deinit(allocator);
}

// Property introspection
var prop = try property.parse(allocator);
defer prop.deinit(allocator);
```

## 7. Differential Verification Against Apple Clang

To ensure 100% fidelity with the Apple compiler toolchain, all primitive, aggregate, and method encodings are differential-tested against native Clang `@encode(...)` output compiled into `tests/fixtures/encoding/fixtures.m`.

```bash
# Run all encoding unit and differential tests
zig build test-encoding --summary all
```
